❓ HELP & SUPPORT

I don't have quizzes generating — what's wrong?
Open your profile icon (top-left) → ⚙️ SET, and make sure a Gemini API key is entered. It's free — get one at aistudio.google.com/apikey. A Groq key is optional and just makes text-based quizzes faster.
Why did my YouTube video fail to import?
YouTube blocks direct browser access to transcripts. If you've added a RapidAPI key in Settings we'll try that automatically; otherwise (or if it fails) copy the transcript yourself from YouTube's "⋯ → Show transcript" menu and paste it into the manual box that appears.
How do I install this as an app?
On Android/desktop Chrome or Edge, use the browser's "Install app" option, or Settings → "Install as App" inside this app. See BUILD_INSTRUCTIONS.md in the project files for a real .apk / .exe.
Is my data private?
Everything — your notes, PDFs, quiz history, API keys, and login profile — is stored only in this browser on this device. Nothing is uploaded to a server we control. AI requests go directly from your browser to Google/Groq using your own key.
